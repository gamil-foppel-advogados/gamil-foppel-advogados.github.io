# Client publishing policy

## Canonical URL rule

Before any client-facing publication:

1. Never present a personal or agency account URL as the final client URL. This includes default GitHub Pages addresses such as `https://<account>.github.io/<repository>/`.
2. Use a verified client-owned custom domain as the canonical URL whenever one is available.
3. If there is no custom domain, use only a client-owned GitHub organization named for the company, so the public address carries the company brand.
4. When neither option exists, treat the deployment strictly as a preview. Do not call it final or hand it to the client as the definitive address.
5. Never guess or configure a `CNAME` without verified ownership and DNS access.
6. Before handoff, verify the exact branded public URL, its assets, mobile presentation, and primary interactions.
